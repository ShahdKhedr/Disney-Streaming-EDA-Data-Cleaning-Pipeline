# 🎬 Disney+ StreamLens: Data Preprocessing & EDA

> **Disney+ StreamLens** is a data analysis project focused on the Disney+ catalog. It features a full preprocessing pipeline—handling missing data, feature engineering, and cleaning—followed by EDA to uncover key insights into content distribution, release trends, audience ratings, and genres.
